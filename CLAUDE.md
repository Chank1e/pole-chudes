# pole-chudes — заметки для агента

## OBS и хромакей (`?chroma=1`)

Страницы табло (`/board`, `/safe/board`) используются как **Browser Source** в OBS с фильтром «Хромакей» по цвету `#00ff00`.

### Жёсткие правила (не нарушать)

1. **Фон страницы при `?chroma=1`** — только сплошной `#00ff00`. Никаких градиентов, теней и декора на `body` / `.safe-board-root` / `.board-root`.

2. **Весь визуал розыгрыша — внутри «коробки» игры** (сейф, поле букв). За пределами коробки на зелёном фоне ничего не рисуется:
   - нельзя `position: fixed` оверлеи на весь экран;
   - нельзя canvas/confetti/fireworks на весь `.safe-board__stage` или `#root`;
   - нельзя `filter: drop-shadow` / `box-shadow` с размытием **наружу** от сейфа — зелёный «загрязняется», хромакей ломается.

3. **Анимации сейфа** — только внутри `.safe-visual__interior` с `overflow: hidden`:
   - гора алмазов;
   - конфетти и летящие камни (canvas);
   - вспышки и искры.
   Дверь (`safe-visual__door`) — снаружи интерьера, открывается и **открывает** уже нарисованное внутри.

4. **Не использовать цвета близкие к ключу** в частицах и эффектах: `#00ff00`, яркий `lime`, `hsl(120…)`. Конфетти — жёлтый, синий, розовый, фиолетовый, оранжевый.

5. **Слои поверх хромакея запрещены.** Если эффект «вылезает» из сейфа — это баг. Исправление: перенести DOM/canvas в `interior`, клип `overflow: hidden`, убрать внешние тени.

6. **Превью без хромакея** (`/safe/board` без query) может иметь фон-градиент и тень у сейфа; **с `?chroma=1`** — класс `.safe-visual--chroma`: без тени, без внешнего glow на корпусе (только `inset` тени).

### URL для OBS

| Интерактив   | Панель ведущего | Табло (хромакей)              |
|-------------|-----------------|-------------------------------|
| Поле чудес  | `/host`         | `/board` (+ настройка фона)   |
| Сейф        | `/safe/host`    | `/safe/board?chroma=1`        |

### Архитектура сейфа

```
safe-visual__body
  safe-visual__interior   ← overflow:hidden, всё сокровище и canvas
  safe-visual__door       ← закрывает interior, уезжает при open
```

Компонент `SafeTreasureBurst` принимает `clipRef` на `interior`, не на stage.

## Запуск

- Prod: `npm run serve` — :8080

## WebSocket роли

- Поле: `host` | `board`
- Сейф: `safe-host` | `safe-board` (отдельное состояние, не мешает полю)
